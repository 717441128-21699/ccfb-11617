# 拉坯 · 陶艺模拟

一个有"手感"的陶艺拉坯休闲游戏:泥要先定中心,手往上提泥才会拉高变薄,
水加少了泥发涩会被拧裂,壁太薄或口沿外撇太多会塌坯。

## 运行

```bash
npm install
npm run dev        # 开发服务器
npm test           # 物理验收测试(14 项)
npm run build      # 类型检查 + 打包
npm run tune       # 重标定泥料强度系数(改物理参数后用)
npm run smoke      # 浏览器全流程冒烟(需本机装有 Chrome, 先起 dev 服务器并把端口写进 scripts/smoke.ts)
```

## 玩法

1. **泥料页**: 五种泥(粗陶/细陶/炻器/白瓷/紫砂), 塑性、硬度、耗水、收缩率各不相同。
2. **拉坯台**: 指针纵坐标 = 手的高度; 横向压向泥坯轮廓 = 压力。
   先在中下部稳住手把偏摆压到 1mm 以下(定中心), 再一边**向上提**一边轻压把坯拉高。
   按住 `W`/空格或"补水"按钮加水。转速用滑块调。
3. **修坯页**: 皮革硬度下用刀具切削, 切掉的体积实时从坯体扣除并显示。
4. **作品架**: 阴干后按泥料线收缩率变小, 存档在 localStorage。

## 物理模型(src/sim/claySim.ts)

- 泥坯 = 160 个拉格朗日材料圆环, 每环体积守恒, 由 (v, r, h) 推出壁厚与内半径。
- **泥的流动**: 手挤压只改变半径(体积守恒→局部鼓起); 手上提时通过半拉格朗日
  平流把泥带上去, 速度梯度处器壁被拉长拉薄(总体积归一守恒)。手不提, 泥不长。
- **定中心**: 中下部稳定施压使偏摆收敛; 没定中心就上拉, 偏摆随拉升量指数放大。
- **水**: 摩擦耗水, 水少发涩 → 继续上手累积拧裂。
- **塌坯**: 逐环核算 自重应力 + 离心应力 vs 壁厚决定的生坯强度;
  壁厚低于 1.6mm、口沿外撇斜率超过 2.1、或偏摆失控都直接判塌。
- **修坯/阴干**: 刀具切削按几何精确扣体积; 阴干按泥料线收缩率整体缩小。

## 验收口径

- **经验表**: `src/sim/clays.ts` 的 `maxRatio`(最大 坯高/壁厚)。`src/sim/optimizer.ts`
  模拟标准手法(定中心→保湿→匀速多道提拉), vitest 断言五种泥的实测比值与经验表
  相差 ≤15%(当前标定误差 <0.2%)。强度系数用 `npm run tune` 二分标定。
- **延迟**: 渲染网格 21696 顶点(外壁 160×96 + 内壁 64×96 + 口沿)。物理步进 ~0.4µs/帧,
  每帧 CPU 重建顶点 + 一次 bufferSubData, 输入到上屏一帧内完成。拉坯台 HUD 实时显示
  "操作延迟", 浏览器冒烟实测最大 13.9ms(预算 20ms)。
